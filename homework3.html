01Introduction and model definition

The experiment models a penetration score as a sum of independent random increments. The number of steps n represents the system size, and the goal is to see how the total score and its normalized versions behave as the system grows.

Sn = Σi=1n Xi     S̄n = Sn / n     Zn = Sn / √n
  • Total score Sn: accumulated penetration score over all steps.
  • Average score S̄n: average score per step (Law of Large Numbers).
  • Normalized score Zn: total scaled by √n (Central Limit Theorem).

Models. Bernoulli: Xi ∈ {0, 1} with P(Xi = 1) = p, so μ = p and σ² = p(1−p). Rademacher: Xi ∈ {−1, +1} with probability ½ each, so μ = 0 and σ² = 1.

What does m mean here? The assignment defines only the increments Xi, not how m enters. This page therefore treats m as the number of independent attackers, each generating n increments with the selected model. Sn, S̄n and Zn keep their original definitions (one attacker), and the aggregate An(m) = Σj=1m Sn(j) is studied separately in Section 7. To reuse the same simulation, attackers are formed by grouping m disjoint runs, giving ⌊R/m⌋ aggregate samples. Independence between attackers is an assumption, not something the assignment specifies.

05Central Limit Theorem

Zn = Sn / √n → N(0, 1) in distribution (Rademacher)

Bernoulli extension. With p > 0, E[Sn/√n] = p√n grows with n, so the uncentered Zn does not converge to N(0,1). The histogram above uses the centered statistic (Sn − np)/√(np(1−p)). The uncentered version is shown below against N(0,1) to display the shift.

Kolmogorov–Smirnov distance to N(0,1)

DR = supx |F̂R(x) − Φ(x)|, evaluated at each n from the same runs. It mixes finite-n effects (including lattice discreteness) with finite-R noise (dashed line ≈ 1.36/√R), so it need not decrease monotonically.

06Variance under different normalizations

Solid: empirical (unbiased, denominator R−1). Dashed: theory. Log–log axes.

Var(Sn) = nσ² grows linearly, Var(Sn/n) = σ²/n decays like 1/n, and Var(Sn/√n) = σ² stays constant (σ² = p(1−p) for Bernoulli, 1 for Rademacher).

07Number of attackers m

An(m) = Σj=1m Sn(j),   E[A] = mnμ,   Var(A) = mnσ²,   Var(A/(mn)) = σ²/(mn)
More independent attackers raise the expected aggregate (when μ > 0) and always raise its variance linearly in m, while the per-attacker, per-step average becomes more concentrated. This relies on the independence assumption; interacting attackers are not modeled. Rows with few groups (⌊R/m⌋ small) have noisy empirical values.
