Riemann and Lebesgue Integration

01 · Introduction
Understanding the two approaches

Riemann: partition the x-axis

IR = Σ f(xi*)·Δx,   Δx = (b−a)/n,   xi* = a+(i+½)Δx

Lebesgue: partition the y-axis

IL ≈ Σ yj*·μ(Aj),   Aj = {x : f(x) ∈ Bj}

The Lebesgue-inspired method is a numerical discretisation, not an exact measure computation: μ(Aj) is estimated as (points in level j / N)·(b−a). Here n (Riemann subintervals) and N (domain samples) count points on the x-axis, while k counts value levels on the y-axis; they are different quantities.

05 · Discussion
Interpretation and conclusions

Conclusion of Exercise 1

For Riemann-integrable functions the two approaches converge to the same integral, provided the approximations are built correctly. The real difference lies in how the computation is organised (slicing the domain versus grouping points by value) and in how each approach behaves on unusual functions: unbounded ones need truncation, and the Dirichlet function exposes the fact that a finite sample cannot tell rational from irrational numbers.

Numerical Computation of the Normal CDF

01 · Mathematical Background
The standard normal distribution

φ(x) = (1/√(2π))·e−x²/2     Φ(x) = ∫−∞x φ(t) dt = P(Z ≤ x)

Φ(0) = 0.5 and Φ(1) ≈ 0.84134: about 84.13% of a standard normal variable lies below 1. Move the cursor to see the cumulative area.

02 · Theoretical Foundations
Why is the CDF not elementary?

Liouville's theorem on integration in finite terms says that if an elementary function has an elementary antiderivative, the antiderivative has a restricted form. For f = eh with h rational, it exists only if ∫eh dx = r(x)·eh with r a rational function, i.e.

r′(x) + h′(x)·r(x) = 1

For h = −x² this reads r′ − 2x·r = 1. If r is a polynomial of degree d ≥ 0, the left side has degree d+1 ≥ 1, never the constant 1 (and r = 0 gives 0). If r has a pole of order m at some point, r′ has a pole of order m+1 while 2x·r has order at most m, so they cannot cancel. No rational r exists, hence ∫e−x²dx is not elementary (see B. Conrad's Stanford notes on this).

This does not mean the integral fails to exist or cannot be computed: only that no finite combination of polynomials, exponentials, logarithms, trigonometric and algebraic functions gives its antiderivative.

The error function

erf(x) = (2/√π)·∫0x e−t² dt     Φ(x) = ½·[1 + erf(x/√2)]

The relation Φ ↔ erf is an exact identity, so special functions give an exact analytical representation. But erf is itself non-elementary: to get a number we still need numerical integration, a truncated series or a rational approximation. That is exactly what the three methods below do.

03 · Method Explorer
Compare numerical algorithms

A · Simpson (integration)

Φ(x) = 0.5 ± (h/3)·[f0 + fn + 4Σodd + 2Σeven]

Integrates φ from 0 to |x| and uses symmetry. Accuracy set by the even number of subintervals n; cost grows linearly with n.

B · erf power series

erf(z) = (2/√π)·Σn≥0 (−1)n z2n+1 / (n!(2n+1))

Terms are added until the next one falls below the tolerance. Slower and less stable for large |x| (alternating terms, cancellation).

C · Abramowitz & Stegun

Φ(x) ≈ 1 − φ(x)(b1t + … + b5t5),   t = 1/(1+0.2316419x)

Fixed-cost polynomial approximation (formula 26.2.17), maximum absolute error about 7.5·10−8. It is an approximation, not an exact value.
