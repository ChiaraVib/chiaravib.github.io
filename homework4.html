EXERCISE 1

Welford’s Recurrence Formulas

1. Mathematical Derivation

Calculating variance via the standard formula Var(X) = E[X²] - (E[X])² requires two passes over the data or storing all observations. Furthermore, computing large sums of squares can lead to numerical instability (catastrophic cancellation). Welford's algorithm updates mean and variance incrementally in one pass.

Step A: Sample Mean & Knuth's Recurrence

Given the sample mean x̄n = (1/n) Σi=1..n xi, when a new score xn arrives:

x̄n = x̄n-1 + (xn - x̄n-1) / n
Step B: Sum of Squared Differences (SS)

Define SSn = Σi=1..n (xi - x̄n)². Let δ = xn - x̄n-1. The recurrence for the sum of squares simplifies to:

SSn = SSn-1 + (xn - x̄n-1)(xn - x̄n)
Step C: Unbiased Sample Variance

Dividing SSn by the degrees of freedom (n - 1) yields the unbiased sample variance sn²:

sn² = SSn / (n - 1)   (for n > 1)

2. Core JavaScript Code

The central update logic requires only 3 lines of code:

// 3-Line Welford Core Update
const delta = x - mean;
mean += delta / n;
SS += delta * (x - mean);

// Unbiased sample variance derivation
const variance = n > 1 ? SS / (n - 1) : null;

EXERCISE 2

Sampling Mean and Variance

Simulation Model

We model m hackers, each attempting penetration on n systems. Scores for each system are drawn independently from a continuous Uniform distribution X ~ U(0, 10).

Theoretical Parameters

• Expected Mean: μ = (0+10)/2 = 5.0000
• Expected Var: σ² = (10-0)²/12 = 100/12 ≈ 8.3333

Experiment Goals

For each hacker trajectory, compute sample mean (x̄) and sample variance (s²) using Welford's algorithm. Evaluate grand averages across all m hackers as system count n increases.

Monte Carlo Simulation Logic

const hackerMeans = [];
const hackerVariances = [];

for (let h = 0; h < m; h++) {
    let mean = 0, SS = 0;
    for (let i = 1; i <= n; i++) {
        const score = Math.random() * 10;
        const delta = score - mean;
        mean += delta / i;
        SS += delta * (score - mean);
    }
    hackerMeans.push(mean);
    hackerVariances.push(SS / (n - 1));
}

Statistical Interpretations & Conclusions

1 Convergence of Sample Mean (Law of Large Numbers)

Increasing n causes individual sample means (x̄) to converge toward the theoretical population mean (μ = 5.0). Across m = 1000 hackers, the grand average of sample means closely matches 5.0 for any sample size n.

2 Unbiasedness of Sample Variance

Dividing Welford's Sum of Squares by (n - 1) ensures the expected value of sample variance equals the theoretical variance: E[s²] = σ² ≈ 8.3333. The average sample variance remains unbiased even for small sample sizes like n = 5.

3 Reduced Variability Across Hackers

The dispersion of sample means across hackers decreases proportional to sample size: Var(x̄) = σ² / n. Increasing n from 5 to 500 reduces variance among sample means by a factor of 100, yielding far more predictable estimations.

4 Utility in Inferential Statistics

In practice, complete population data is rarely observable. This experiment proves that sample estimators (x̄ and s²) reliably approximate unknown population parameters (μ and σ²), enabling valid hypothesis testing and confidence intervals.
